# Card back artwork

Generated using the built-in imagegen tool. Saved as `card-back.png`; portrait 1060 × 1484 pixels (5:7).

## Use in the current editor

The published project references this original image through `manifest.json` → `cardBack.image`. Use **Define card back** beside the print buttons to select or replace it, or **Remove card back** for front-only sheets. Newly selected backs are packaged under `graphics/` when you **Save project**, with the saved manifest updated to match. Print the front/back sheets double-sided, landscape, flip on the short edge.
