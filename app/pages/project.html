    Suggest a layout from my CSV columns

    Choose the content columns you want printed, in CSV order. The first becomes the heading; the rest become body boxes below the image. For organism cards, the default layout above already provides the requested name / family / category order.

    Match CSV columns to content boxes

    Check the suggested matches. Unmapped columns are listed before import. To keep a new column, add a box in the layout, then map it here.

    Card layout

    SVG designs show the complete card in Inkscape and carry layout JSON plus editable field attributes. Import reads the embedded layout metadata; save to apply it. Finished card SVGs are separate exports.

    Drag a box to move it; drag its bottom-right handle to resize it. Use the measurements for precise changes. All measurements are points (72 pt = 1 inch). Red preview outlines mean text does not fit.

    Corners and borders

    Set radius to 0 for square corners, or border thickness to 0 for no border. Corner radii are limited by the shape’s size.
