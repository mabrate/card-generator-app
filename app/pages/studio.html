TEACHER STUDIO

A layout for your card collection.

Start with a CSV, or design a layout and download its spreadsheet template. Students use your saved layout; they cannot move its boxes.

1 · Choose a project

2 · Import data, or start with the layout below

Demo: select demo/v2/campus-food-web-cards.csv, then all files inside demo/v2/graphics. Image filenames must match exactly; folder paths are not needed.

Suggest a layout from my CSV columns

Choose the content columns you want printed, in CSV order. The first becomes the heading; the rest become body boxes below the image. For organism cards, the default layout above already provides the requested name / family / category order.

Match CSV columns to content boxes

Check the suggested matches. Unmapped columns are listed before import. To keep a new column, add a box in the layout, then map it here.

3 · Shape the card

Drag a box to move it; drag its bottom-right handle to resize it. Use the measurements for precise changes. All measurements are points (72 pt = 1 inch). Red preview outlines mean text does not fit.

Corners and borders

Set radius to 0 for square corners, or border thickness to 0 for no border. Corner radii are limited by the shape’s size.

    Add a content box

    Up to 12 text boxes. Existing card field keys cannot be removed.

    Download Excel template (.xlsx)Download spreadsheet template (.csv)

    The template contains one column for each content box, plus card_id, card_kind, copies, image_filename, and theme. Open it in Excel, Numbers, or LibreOffice. Add one card per row and save as UTF-8 CSV. Saving layout changes returns approved cards to Submitted for review.
